# EchoPledge

Private Reports. Verifiable Response.

EchoPledge is a privacy-conscious institutional accountability
platform built on Solana using Rust and Anchor.

## Project Overview

EchoPledge enables walletless reporting while using Solana
smart contracts to enforce institutional acknowledgment
deadlines through programmable accountability bonds.

## Technology Stack

- Blockchain: Solana Devnet
- Smart Contracts: Rust + Anchor
- Frontend: Next.js + TypeScript
- Backend: Node.js
- Database: Supabase
- Tokens: DEMO tokens (Devnet only)
